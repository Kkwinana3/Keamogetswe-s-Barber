# Keamogetswe's Barbershop Website

**Slogan:** *Look Fresh, Clean and Feel Confident*

## 📖 Project Overview
This website serves as the official digital platform for Keamogetswe's Barbershop, offering clients information on haircut services, beard care products, VIP grooming packages, and online appointment enquiries.

---

## 📝 Changelog & Part 2 Feedback Implementations

### Version 3.0.0 — Part 3 Updates

#### 1. Feedback Corrections & Enhancements from Part 2
* **Responsive Layout:** Corrected mobile viewport issues in `css_assets/style.css` so forms and navigation menus collapse cleanly on screen widths below 600px.
* **Semantic HTML Overhaul:** Replaced non-semantic `<div>` layout structures across `index.html`, `about.html`, `services.html`, `products.html`, `enquiry.html`, and `contact.html` with appropriate `<main>`, `<section>`, `<article>`, and `<header>` elements.
* **Image Asset References:** Verified and updated all `<img>` paths to correctly link to images in `_images/` (such as `barbershop.jpeg`, `beard conditiner.jpeg`, and `vip package.jpeg`).

#### 2. JavaScript Interactive Elements & Dynamic Features
* **Live Client-Side Search:** Implemented instant text-filtering logic in `javascript_assets/script.js` to search products and services dynamically.
* **Asynchronous AJAX Enquiry Form (`enquiry.html`):** Integrated client-side validation checking South African phone number formats, character lengths, and email structures. Upon validation, the form dynamically outputs estimated costs and availability without reloading the page.
* **Contact Form Validation (`contact.html`):** Built custom validation checking minimum length constraints prior to mail dispatch.

#### 3. SEO Optimization
* **On-Page SEO:** Added targeted meta descriptions, keyword tags, Open Graph tags, and structured heading tags (`<h1>`, `<h2>`) across all HTML files.
* **Image Optimisation:** Added descriptive `alt` tags to all barbershop gallery images.
* **Technical SEO Files:** Added `robots.txt` and `sitemap.xml` to the root directory.

#### 4. Version Control & Deployment
* **Git Version Control:** Regularly committed code updates with clear, descriptive commit messages.
* **Live Deployment:** Deployed on GitHub Pages / Netlify.
